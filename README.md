# Simple Interest Calculator

## Purpose
This project is a simple interest calculator designed to easily compute the interest based on the principal amount, annual rate of interest, and time period.

## How to Use It
1. Enter the Principal amount.
2. Enter the Rate of Interest (in percentage).
3. Enter the Time period (in years).
4. Run the script to get the calculated Simple Interest.

## Example
- Principal (P) = $1000
- Rate of Interest (R) = 5% per annum
- Time (T) = 2 years
- Simple Interest = (P * R * T) / 100 = (1000 * 5 * 2) / 100 = $100
